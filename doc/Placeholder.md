

## Placeholder, that can be used in dialogs

### General

Placeholder				| used for
----------------------- | ---------
'$FARMERNAME$'			| will be replaced with your caracter name.

### Underwear

Placeholder					| used for
------------------------------------------| ---------
'$UNDERWEAR_NAME$'                        | will be replaced with the name of the underwear you actual weared.
'$NEW_UNDERWEAR_NAME$'			              | will be replaced with the name of the new underwear you get changed into.
'$OLD_UNDERWEAR_NAME$'			              | will be replaced with the name of you old underwear if you get changed.
'$UNDERWEAR_PREFIX$'                      | will be replaced with the number prefix of the underwear you actual weared.
'$NEW_UNDERWEAR_PREFIX$'		              | will be replaced with the number prefix of the new underwear you get changed into.
'$OLD_UNDERWEAR_PREFIX$'		              | will be replaced with the number prefix of you old underwear if you get changed.
'$UNDERWEAR_DESC$'		                    | will be replaced with the description of the underwear you actual weared.
'$NEW_UNDERWEAR_DESC$'                    | will be replaced with the description of the new underwear you get changed into.
'$OLD_UNDERWEAR_DESC$'                    | will be replaced with the description of you old underwear if you get changed.
'$INSPECT_UNDERWEAR_NAME$'                | will be replaced with the state, name and number prefix of the underwear you actual weared.
'$INSPECT_UNDERWEAR_NAME_NO_PREFIX$'      | will be replaced with the state and name of the underwear you actual weared.
'$INSPECT_NEW_UNDERWEAR_NAME$'            | will be replaced with the state, name and number prefix of the underwear you get changed into.
'$INSPECT_NEW_UNDERWEAR_NAME_NO_PREFIX$'  | will be replaced with the state and name of the underwear you get changed into.
'$INSPECT_OLD_UNDERWEAR_NAME$'            | will be replaced with the state, name and number prefix of you old underwear if you get changed.
'$INSPECT_OLD_UNDERWEAR_NAME_NO_PREFIX$'  | will be replaced with the state and name of you old underwear if you get changed.
'$INSPECT_UNDERWEAR_DESC$'                | will be replaced with the state, description and number prefix of the underwear you actual weared.
'$INSPECT_NEW_UNDERWEAR_DESC$'            | will be replaced with the state, description and number prefix of the underwear you get changed into.
'$INSPECT_OLD_UNDERWEAR_DESC$'            | will be replaced with the state, description and number prefix of you old underwear if you get changed.

### Overnight

Placeholder							| used for

### For Changing Dialogs

Placeholder								| used for
--------------------------------------- | ---------
'$GETTING_CHANGED_DIALOG$'				      | will be replaced with a dynamicly created dialog, where you ask an npc for a underwear change and you can accept or refuse the offer.<br><br> You can find a detailed description in the [changingPlayer.md](ChangingPlayer.md).
'$GET_CHANGE_PLAYER_ACCEPT_DIALOG$'		  | will be replaced with a dynamicly created dialog, when you accept the changing offer,<br> you get by an npc that was created by the '$GETTING_CHANGED_DIALOG$' placeholder.<br><br> You can find a detailed description in the [changingPlayer.md](ChangingPlayer.md).
'$GET_CHANGE_PLAYER_REFUSE_DIALOG$'		  | will be replaced with a dynamicly created dialog, when you refuse the changing offer,<br> you get by an npc that was created by the '$GETTING_CHANGED_DIALOG$' placeholder.<br><br> You can find a detailed description in the [changingPlayer.md](ChangingPlayer.md).
'$$CHANGED_BY_NPC$$'				      | will be replaced with a dynamicly created dialog, where you ask an npc for a underwear change.<br><br> You can find a detailed description in the [changingPlayer.md](ChangingPlayer.md).
'$CHANGE_OTHER_DIALOG$'					        | will be replaced with a dynamicly created dialog, where you ask an npc if you should change that underwear and you can chose the underwear, you want to change them.<br><br> You can find a detailed description in the [changingNpc.md](ChangingNpc.md).
